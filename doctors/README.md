# МедКарта Врачи

Отдельная версия МедКарты для каталога конкретных врачей. Исходное приложение в корне проекта не изменяется.

## Запуск

Из корня проекта запустите локальный сервер:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000/doctors/`.

## Данные

Приложение использует 62 карточки из вкладки `Полные данные` предоставленной Google Таблицы. Встроенный снимок позволяет открыть каталог без сети. При доступном источнике данные обновляются при открытии, каждые пять минут, после возвращения на вкладку и по кнопке ↻.

Изменения, сделанные через интерфейс, хранятся только в браузере и используют отдельные ключи `medkarta-doctors-*`, поэтому не пересекаются с первой версией приложения.

Интерактивная карта построена на Leaflet и OpenStreetMap. Библиотека Leaflet хранится внутри проекта, поэтому её загрузка не зависит от внешнего CDN. Для маркера используется первый адрес приёма из карточки; положение ориентировочное. Цена, расписание и доступность онлайн-приёма требуют подтверждения в клинике.
