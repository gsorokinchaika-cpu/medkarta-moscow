# МедКарта — Москва и Орск

Публичный снимок каталога: 62 врача Москвы и 37 учреждений/служб Орска. На карте Орска — 36 учреждений и 37 адресных точек; скорая помощь является выездной службой.

## Для коллег

Откройте сайт, выберите город и пользуйтесь поиском по специалистам, диагностике, названию или адресу. Суффикс `?city=Орск` сразу открывает Орск, `?city=Москва` — Москву. Контакты, условия обращения, публичные источники и даты проверки указаны в карточках. Время Орска — местное, UTC+5.

Если значки перекрываются, нажатие предлагает выбрать учреждение. Для картографической подложки нужен интернет. Каталог загружается из файлов сайта.

Эта публичная версия не подключается к Google Таблице: синхронизация и настройки источника удалены, адреса и идентификаторы внутренней таблицы в комплект не включены. Каталог обновляется новой публикацией файлов владельцем.

Добавления, исправления и удаления через интерфейс сохраняются только в вашем браузере, не отправляются на сервер и не видны коллегам. Новая публикация обновляет встроенные записи и сохраняет ваши локальные правки. Другой браузер или адрес сайта имеют отдельное локальное хранилище.

## Публикация

Файлы предназначены для статического сайта GitHub Pages: разместите их в корне или в подкаталоге `doctors/`. Относительные пути работают в обоих случаях. Сохраните `vendor/leaflet/` с лицензией; `.nojekyll` предназначен для корня публикуемого сайта. Сборка на сервере и установка зависимостей не нужны.

Комплект воспроизводимо готовится владельцем командой `node deployment/prepare-github-pages.cjs` из рабочего проекта. Скрипт использует явный список файлов, создаёт отдельную версию без удалённых источников и проверяет отсутствие исходных идентификаторов. Оригинальное рабочее приложение не меняется.

Состав публикации — `publish-files.txt`; численность снимка и SHA256 файлов — `publication-manifest.json`. Рабочие документы, исследования, тесты и содержимое браузерного хранилища автора не включены. Файлы каталога доступны посетителям сайта.

Для локального просмотра: `python3 -m http.server 8000` в этой папке, затем `http://localhost:8000/`.

Картография: OpenStreetMap. Библиотека: Leaflet, лицензия `vendor/leaflet/LICENSE`.
