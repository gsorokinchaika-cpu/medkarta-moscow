# МедКарта

Небольшое статическое приложение для медицинского ассистента: поиск и фильтрация врачей, клиник и исследований на схематичной карте Москвы.

Стартовый каталог заполнен 36 учреждениями из предоставленного [файла на Google Drive](https://docs.google.com/spreadsheets/d/1w55BqwgeNZTaxhsiq6tz3-UG9n92TwBu/edit?gid=723850286#gid=723850286) (снимок от 28.08.2026).

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```sh
python3 -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

## Подключение Google Sheets

1. В Google Sheets выберите **Файл → Поделиться → Опубликовать в интернете** и опубликуйте нужный лист как CSV.
2. В приложении нажмите «Подключить таблицу» и вставьте ссылку на опубликованный CSV.
3. Загруженные карточки сохраняются в браузере. При следующем открытии будут доступны последние данные; повторно нажмите «Подключить таблицу», чтобы обновить их.

Приложение принимает текущую структуру файла: `Краткое название`, `Адрес`, `Основные направления`, `Возраст`, `Уровень учреждения`, `Формат помощи`. Для неё район и положение на карте определяются ориентировочно по адресу.

Также поддерживается универсальный формат колонок:

| name | type | specialty | district | x | y |
|---|---|---|---|---:|---:|
| Мария Андреева | doctor | Кардиология | Хамовники | 48 | 42 |

Дополнительные поля: `metro`, `price`, `services`, `note`. Значение `type`: `doctor`, `clinic` или `research`. Координаты `x` и `y` — числа от 0 до 100, которые указывают условное положение точки на карте.

Карточки можно добавлять и редактировать прямо в интерфейсе; изменения сохраняются локально в браузере.
