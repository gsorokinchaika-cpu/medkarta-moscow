# МедКарта

Небольшое статическое приложение для медицинского ассистента: поиск и фильтрация врачей, клиник и исследований на схематичной карте Москвы.

Стартовый каталог заполнен учреждениями из предоставленного [файла на Google Drive](https://docs.google.com/spreadsheets/d/1w55BqwgeNZTaxhsiq6tz3-UG9n92TwBu/edit?gid=723850286#gid=723850286). После загрузки приложение автоматически получает актуальную версию таблицы.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```sh
python3 -m http.server 8000
```

Затем перейдите на `http://localhost:8000`.

## Подключение Google Sheets

Исходная таблица уже подключена. Приложение обновляет её:

- при каждом открытии;
- каждые пять минут, пока приложение открыто;
- при возвращении на вкладку после паузы;
- вручную по кнопке ↻ рядом со ссылкой на источник.

Последняя успешно загруженная версия сохраняется в браузере и остаётся доступной при временной ошибке сети. Другой публичный источник можно указать через кнопку «Настроить источник».

Приложение принимает текущую структуру файла: `Краткое название`, `Адрес`, `Основные направления`, `Возраст`, `Уровень учреждения`, `Формат помощи`. Для исходного каталога уже сохранены реальные координаты клиник — при повторном импорте они сопоставляются по названию. Для новых строк без координат положение определяется ориентировочно по району.

Также поддерживается универсальный формат колонок:

| name | type | specialty | district | latitude | longitude |
|---|---|---|---|---:|---:|
| Мария Андреева | doctor | Кардиология | Хамовники | 55.734 | 37.579 |

Дополнительные поля: `metro`, `price`, `services`, `note`, `address`. Значение `type`: `doctor`, `clinic` или `research`. Для точного положения добавляйте `latitude` и `longitude` (или `lat` и `lng`); резервные `x` и `y` от 0 до 100 поддерживаются для условного размещения.

Карточки можно добавлять и редактировать прямо в интерфейсе; изменения сохраняются локально в браузере.
